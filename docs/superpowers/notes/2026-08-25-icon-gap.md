# Icon set gap — M4 Task 3

The 26-icon Figma set does **not** cover what the current screens use, so Lucide
cannot be removed in M4 Task 3 as the plan assumed. Recording the shortfall
rather than papering over it in either direction.

## Mapped — 9 of 21

`X→Close`, `Mail→Mail`, `Lock→Lock`, `Clock→Clock`, `Download→Download`,
`Upload→Upload`, `Moon→Moon`, `Sun→Sun`, `CheckCircle→Check`

## Missing — 12

`AlertCircle`, `Briefcase`, `ChevronDown`, `GripVertical`, `Loader2`, `LogOut`,
`RotateCcw`, `Save`, `Sparkles`, `Target`, `Trash2`, `User`

These are not decoration. `ChevronDown` is every disclosure control,
`GripVertical` is the kanban drag affordance, `Loader2` is every pending state,
`Trash2` and `Save` are destructive and primary actions respectively, and
`AlertCircle` carries error states.

## Drawn but unused — 13

`Overview`, `Applications`, `Calendar`, `Documents`, `Analytics`, `Settings`,
`Menu`, `ArrowRight`, `External`, `Database`, `Shield`, `Swatch`, `Text`,
`Layers`, `Play`

The set was drawn for the *redesigned* navigation and marketing surfaces, which
do not exist yet. That is why the overlap with today's screens is so thin — it
is a set built for M5 and M6, being measured against M0 code.

## Why Lucide stays for now

Uninstalling it breaks the build, and the twelve gaps sit almost entirely in
screens M5 rewrites: `JobsPage`, `ResumePage`, `DashboardPage`, `JobForm`,
`JobCard`, `ResumeVersionHistory`, `TemplatePresetSelector`. Replacing icons in
components that are about to be deleted is churn with a regression risk and no
lasting benefit.

**The roadmap constraint "`grep -r lucide src/` must come back empty" moves from
M4 4.3 to M5.** It is still a hard gate, just at the point where the screens
holding those imports are actually rewritten.

## Decision needed before M5

Twelve icons have to come from somewhere. Three options, in order of preference:

1. **Draw them into the Figma set**, taking it from 26 to 38. Keeps one
   vocabulary and one source of truth. Costs design time.
2. **Reduce the need.** Some are avoidable — `Loader2` can be a CSS spinner with
   no glyph, `Save` and `LogOut` can be text buttons. That removes maybe four.
3. **Accept a second source** for utility glyphs only. Cheapest, and the one the
   roadmap explicitly rejected when it said "never Lucide".

Option 1 for the icons that carry meaning, option 2 where a glyph is not pulling
its weight. Recommend against 3.
