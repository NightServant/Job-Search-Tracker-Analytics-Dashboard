================================================================================
                    TROUBLESHOOTING GUIDE
================================================================================

This document provides solutions to common issues encountered when setting up
and running the Job Search Tracker application.

================================================================================
1. INSTALLATION ISSUES
================================================================================

--------------------------------------------------------------------------------
1.1 Node Modules Installation Fails
--------------------------------------------------------------------------------

SYMPTOM:
  Error during `npm install` with missing dependencies or network errors.

SOLUTIONS:
  1. Clear npm cache:
     ```
     npm cache clean --force
     ```
  
  2. Delete node_modules and package-lock.json:
     ```
     rm -rf node_modules package-lock.json
     npm install
     ```
  
  3. Try using a different registry:
     ```
     npm install --registry=https://registry.npmjs.org/
     ```

  4. Check Node.js version (requires 18+):
     ```
     node --version
     ```

--------------------------------------------------------------------------------
1.2 Vite Build Errors
--------------------------------------------------------------------------------

SYMPTOM:
  TypeScript compilation errors or Vite build failures.

SOLUTIONS:
  1. Ensure all TypeScript files are properly typed
  
  2. Clear Vite cache:
     ```
     rm -rf dist
     npm run build
     ```
  
  3. Check tsconfig.json and tsconfig.node.json configurations
  
  4. Verify all imports use correct paths with @/ alias

================================================================================
2. SUPABASE CONNECTION ISSUES
================================================================================

--------------------------------------------------------------------------------
2.1 "Missing Supabase Environment Variables" Warning
--------------------------------------------------------------------------------

SYMPTOM:
  Console warning about missing VITE_SUPABASE_URL or VITE_SUPABASE_ANON_KEY.

SOLUTIONS:
  1. Create .env.local file in the project root
  
  2. Copy contents from .env.example
  
  3. Replace placeholder values with actual Supabase credentials from
     the Supabase dashboard (Settings > API)
  
  4. Restart the development server after adding environment variables:
     ```
     npm run dev
     ```

  5. Verify the variables are prefixed with VITE_ (required for Vite)

--------------------------------------------------------------------------------
2.2 Authentication Fails / Cannot Sign In
--------------------------------------------------------------------------------

SYMPTOM:
  Login/signup attempts fail with "Invalid credentials" or network errors.

SOLUTIONS:
  1. Verify Supabase credentials are correct in .env.local
  
  2. Check if email confirmation is enabled in Supabase:
     - Go to Authentication > Providers > Email
     - Disable "Confirm email" for development
  
  3. Check browser console for specific error messages
  
  4. Verify the Supabase project is active and hasn't been paused
  
  5. Test Supabase connection directly:
     ```javascript
     const { data, error } = await supabase.auth.getSession()
     console.log(data, error)
     ```

--------------------------------------------------------------------------------
2.3 Database Query Errors (Row Level Security)
--------------------------------------------------------------------------------

SYMPTOM:
  Queries return empty results or "insufficient privilege" errors.

SOLUTIONS:
  1. Verify RLS policies are created in Supabase:
     - Go to Database > jobs table > Policies
     - Ensure all 4 policies exist (SELECT, INSERT, UPDATE, DELETE)
  
  2. Run the complete SQL schema from texts/database_schema.txt
  
  3. Check that auth.uid() matches the user_id in queries
  
  4. Temporarily disable RLS for testing (re-enable after):
     ```sql
     ALTER TABLE jobs DISABLE ROW LEVEL SECURITY;
     ```

  5. Verify the user is authenticated before making queries

================================================================================
3. UI / COMPONENT ISSUES
================================================================================

--------------------------------------------------------------------------------
3.1 Dark Mode Not Working
--------------------------------------------------------------------------------

SYMPTOM:
  Dark mode toggle doesn't change the theme or theme doesn't persist.

SOLUTIONS:
  1. Check if 'dark' class is added to <html> element in browser DevTools
  
  2. Verify ThemeProvider wraps the entire app in App.tsx
  
  3. Clear localStorage and try again:
     ```javascript
     localStorage.removeItem('theme')
     ```
  
  4. Check Tailwind dark mode configuration in tailwind.config.js:
     ```javascript
     darkMode: 'class'
     ```

--------------------------------------------------------------------------------
3.2 Charts Not Displaying
--------------------------------------------------------------------------------

SYMPTOM:
  Dashboard charts show "No data" or fail to render.

SOLUTIONS:
  1. Verify jobs have date_applied values for timeline chart
  
  2. Check browser console for Recharts errors
  
  3. Ensure at least one job exists in the database
  
  4. Verify the data format matches Recharts requirements
  
  5. Check if chart dimensions are correct (ResponsiveContainer)

--------------------------------------------------------------------------------
3.3 Job Cards Not Updating After Edit
--------------------------------------------------------------------------------

SYMPTOM:
  Changes to jobs don't reflect immediately in the UI.

SOLUTIONS:
  1. Check TanStack Query devtools for cache invalidation
  
  2. Verify optimistic updates are working in useUpdateJob hook
  
  3. Clear query cache:
     ```javascript
     queryClient.clear()
     ```
  
  4. Check network tab for successful PUT/PATCH requests

  5. Verify onSuccess callback invalidates the correct query keys

================================================================================
4. ROUTING ISSUES
================================================================================

--------------------------------------------------------------------------------
4.1 404 on Page Refresh (Production)
--------------------------------------------------------------------------------

SYMPTOM:
  Refreshing the page on /dashboard or /jobs returns 404 error.

SOLUTIONS:
  For Vercel:
    - Create vercel.json with rewrites:
      ```json
      {
        "rewrites": [{ "source": "/(.*)", "destination": "/index.html" }]
      }
      ```
  
  For other hosts:
    - Configure the server to serve index.html for all routes
    - Add appropriate .htaccess (Apache) or nginx config

--------------------------------------------------------------------------------
4.2 Infinite Redirect Loop
--------------------------------------------------------------------------------

SYMPTOM:
  Application redirects continuously between login and dashboard.

SOLUTIONS:
  1. Check AuthContext for proper session handling
  
  2. Verify ProtectedRoute logic in App.tsx
  
  3. Check if loading state is properly handled before redirects
  
  4. Clear browser cookies and localStorage
  
  5. Check for conflicting route guards

================================================================================
5. DATA EXPORT ISSUES
================================================================================

--------------------------------------------------------------------------------
5.1 CSV Export Fails or Downloads Empty File
--------------------------------------------------------------------------------

SYMPTOM:
  Clicking "Export CSV" doesn't download anything or downloads empty file.

SOLUTIONS:
  1. Verify jobs array has data before export
  
  2. Check browser console for JavaScript errors
  
  3. Test in a different browser (popup blockers may interfere)
  
  4. Verify the exportToCSV function properly formats the data
  
  5. Check if special characters in notes field are properly escaped

--------------------------------------------------------------------------------
5.2 Python Analysis Script Errors
--------------------------------------------------------------------------------

SYMPTOM:
  data_analysis.py fails with import errors or data parsing issues.

SOLUTIONS:
  1. Install required packages:
     ```
     pip install pandas matplotlib seaborn
     ```
  
  2. Verify CSV file path is correct
  
  3. Check CSV encoding (should be UTF-8)
  
  4. Ensure date_applied column has valid date format
  
  5. Run with Python 3.8+:
     ```
     python --version
     ```

================================================================================
6. PERFORMANCE ISSUES
================================================================================

--------------------------------------------------------------------------------
6.1 Slow Initial Load
--------------------------------------------------------------------------------

SYMPTOM:
  Application takes a long time to load initially.

SOLUTIONS:
  1. Enable code splitting in vite.config.ts
  
  2. Lazy load heavy components (Dashboard, Charts)
  
  3. Optimize bundle size:
     ```
     npm run build -- --report
     ```
  
  4. Use dynamic imports for large dependencies
  
  5. Consider CDN for hosting static assets

--------------------------------------------------------------------------------
6.2 Slow Database Queries
--------------------------------------------------------------------------------

SYMPTOM:
  Jobs list takes a long time to load or update.

SOLUTIONS:
  1. Verify database indexes exist (check database_schema.txt)
  
  2. Add composite indexes for common query patterns
  
  3. Limit the number of jobs fetched initially
  
  4. Implement pagination for large datasets
  
  5. Check Supabase project performance metrics

================================================================================
7. BUILD / DEPLOYMENT ISSUES
================================================================================

--------------------------------------------------------------------------------
7.1 Build Fails in Production
--------------------------------------------------------------------------------

SYMPTOM:
  `npm run build` fails with errors not present in development.

SOLUTIONS:
  1. Check for TypeScript strict mode errors
  
  2. Verify all imports are resolvable
  
  3. Remove unused imports (causes errors in strict mode)
  
  4. Check for environment-specific code
  
  5. Test build locally before deploying:
     ```
     npm run build
     npm run preview
     ```

--------------------------------------------------------------------------------
7.2 Environment Variables Not Working in Production
--------------------------------------------------------------------------------

SYMPTOM:
  Supabase connection fails in deployed app.

SOLUTIONS:
  1. Verify environment variables are set in hosting platform
  
  2. Ensure variables are prefixed with VITE_
  
  3. Redeploy after adding environment variables
  
  4. Check if the hosting platform requires a specific format
  
  5. Verify variables are not being stripped during build

================================================================================
8. GETTING HELP
================================================================================

If the issue persists after trying these solutions:

1. Check the browser console for detailed error messages

2. Enable TanStack Query devtools for debugging data fetching:
   ```javascript
   import { ReactQueryDevtools } from '@tanstack/react-query-devtools'
   ```

3. Check Supabase logs in the dashboard (Logs & Observability)

4. Review the component architecture documentation (texts/component_architecture.txt)

5. Verify the API logic (texts/api_logic.txt)

6. Check GitHub issues for similar problems

7. Create a minimal reproduction of the issue

================================================================================
COMMON ERROR MESSAGES
================================================================================

| Error Message | Likely Cause | Solution |
|---------------|--------------|----------|
| "Module not found" | Missing imports or wrong path | Check import statements |
| "CORS error" | Supabase URL incorrect | Verify VITE_SUPABASE_URL |
| "Network error" | No internet or Supabase down | Check connection |
| "Invalid token" | Expired session | Sign out and sign in again |
| "Cannot read property of undefined" | Data not loaded yet | Add loading checks |
| "Hydration error" | SSR mismatch | Disable SSR or fix mismatch |
